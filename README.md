# 第4章 图表样式美化 - 数据可视化项目

## 项目简介

本项目是基于"第4章 图表样式美化"的内容开发的数据可视化网站，提供强大的图表样式美化功能，支持多种图表类型、配色方案和动画效果，帮助用户创建美观且专业的数据可视化图表。

## 功能特性

### 🎨 图表类型支持
- **柱状图** (Bar Chart) - 适合比较不同类别的数据
- **折线图** (Line Chart) - 适合展示数据趋势变化  
- **饼图** (Pie Chart) - 适合显示数据占比关系
- **散点图** (Scatter Chart) - 适合展示数据分布情况
- **雷达图** (Radar Chart) - 适合多维度数据对比
- **面积图** (Area Chart) - 适合展示数据累积效果

### 🎯 样式美化功能
- **6种配色方案**：
  - 默认配色 - 适合通用场景
  - 海洋配色 - 清新蓝色系
  - 日落配色 - 温暖橙红色系  
  - 森林配色 - 自然绿色系
  - 彩虹配色 - 多彩渐变色系
  - 单色配色 - 专业灰色系

- **4种动画效果**：
  - 无动画 - 简洁快速展示
  - 弹跳动画 - 活泼生动效果
  - 渐变动画 - 平滑过渡效果
  - 滑动动画 - 流畅移动效果

### 🎭 样式预设模板
- **商务风格** - 简洁专业，适合商业报告
- **创意风格** - 活泼生动，适合创意展示
- **学术风格** - 严谨规范，适合学术研究
- **科技风格** - 现代感强，适合技术展示

### 📊 多图表展示
- **主图表区域** - 大尺寸图表展示主要数据
- **对比图表** - 并排对比不同数据系列
- **趋势图表** - 展示数据随时间的变化趋势
- **分布图表** - 显示数据的分布情况
- **占比图表** - 展示各部分占整体的比例

### 🛠 数据管理功能
- **实时数据编辑** - 支持JSON格式数据输入
- **数据验证** - 自动检查数据格式正确性
- **示例数据** - 内置多套示例数据供测试
- **图表导出** - 支持将图表导出为PNG图片

## 技术栈

### 前端框架
- **HTML5** - 页面结构和语义化标签
- **CSS3** - 现代样式设计，包含Grid布局和动画
- **JavaScript ES6+** - 核心交互逻辑

### 图表库
- **ECharts v5.4.3** - 主要图表渲染引擎
- **Chart.js v4.4.0** - 辅助图表功能支持

### 设计特点
- **响应式设计** - 适配桌面和移动设备
- **模块化结构** - 代码组织清晰，易于维护
- **渐进增强** - 优雅降级支持不同浏览器

## 使用指南

### 快速开始

1. **打开网页**
   ```
   直接在浏览器中打开 index.html 文件
   ```

2. **选择图表类型**
   - 在控制面板中选择需要的图表类型
   - 系统会自动更新图表显示

3. **应用样式**
   - 选择配色方案
   - 设置动画效果
   - 调整显示选项
   - 点击"应用样式"按钮

4. **使用预设**
   - 在样式预设区域选择合适的风格
   - 点击"应用预设"快速应用完整样式

### 数据编辑

1. **输入数据格式**
   ```json
   [
     {"name": "数据名称", "value": 数值, "category": "分类"},
     {"name": "数据名称", "value": 数值, "category": "分类"}
   ]
   ```

2. **操作步骤**
   - 在数据编辑器中输入JSON数据
   - 点击"验证数据"检查格式
   - 点击"更新图表"应用新数据

### 图表导出

1. **导出PNG图片**
   - 点击图表区域的"导出"按钮
   - 图片将自动下载到本地

## 开发说明

### 核心模块

1. **图表初始化模块** (`initializeCharts`)
   - 初始化所有图表实例
   - 设置响应式监听

2. **样式控制模块** (`applyStyles`)
   - 统一样式应用接口
   - 支持多种样式参数

3. **数据处理模块** (`getChartOptions`)
   - 根据数据生成图表配置
   - 支持多种图表类型

4. **用户交互模块** (`setupEventListeners`)
   - 处理用户操作事件
   - 实时更新图表显示

### 自定义扩展

1. **添加新图表类型**
   ```javascript
   // 在 getChartOptions 函数中添加新的图表类型处理逻辑
   } else if (chartType === 'yourChartType') {
     return {
       // 配置选项
     };
   ```

2. **添加新配色方案**
   ```javascript
   const colorSchemes = {
     // 添加新的配色方案
     yourScheme: ['#color1', '#color2', '#color3']
   };
   ```

3. **添加新预设样式**
   ```javascript
   const stylePresets = {
     // 添加新的预设配置
     yourPreset: {
       chartType: 'bar',
       colorScheme: 'default',
       // 其他配置...
     }
   };
   ```

## 常见问题

### Q: 图表不显示怎么办？
A: 检查以下几点：
- 确保网络连接正常（CDN资源加载）
- 检查浏览器控制台错误信息
- 验证数据格式是否正确

### Q: 如何自定义配色？
A: 可以通过修改 `colorSchemes` 对象来添加自定义配色方案。

### Q: 支持哪些数据格式？
A: 目前支持JSON格式数据，要求包含 `name`、`value` 和可选的 `category` 字段。
